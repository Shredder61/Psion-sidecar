# Using Sidecar from a Psion

1. Connect the Psion and Raspberry Pi to the same network, or establish your normal supported connection between them.
2. Open the Psion browser and enter `http://<raspberry-pi-address>:8081/`.
3. Use the Quick or Cryptic form to request a crossword number.
4. Select the resulting text file to download it to the Psion.
5. Use the local archive links to retrieve crosswords already downloaded to the Pi.

The homepage also links to FrogFind and, when the index data files are installed, the Psion software catalogue.

The exact steps for connecting a Psion to a network vary by model, browser, and connection hardware. Keep this guide specific to the connection method you have tested, and add your tested model/connection details before publishing a stable release.
